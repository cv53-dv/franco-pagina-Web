# DESIGN SYSTEM

## Filosofía

FRANCO TECH combina minimalismo, tecnología y elegancia.

La inspiración visual está basada en:

- 70% Vercel
- 20% Apple
- 10% Stripe

---

## Principios

- Menos es más.
- Cada elemento debe tener un propósito.
- Priorizar la experiencia del usuario.
- Diseño limpio y profesional.
- Animaciones sutiles.
- Alto rendimiento.
- Accesibilidad.
- Escalabilidad.
